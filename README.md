# the-exact-algebraic-condition-for-clock-behaviour.
Een klok telt niet oneindig door, hij herstart. Die herstart is geen toeval maar een structurele eigenschap: 13 ≡ 1 (mod 12), dus na 12 stappen keert het systeem terug naar zijn beginpunt. Precies dit mechanisme ligt ten grondslag aan elk systeem N = pA + qB waarbij p ≡ 1 (mod q)
